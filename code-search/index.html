Code context that never leaves your network.

code-search is an AI code context engine for air-gapped, CPU-only enterprise environments. It combines Tree-sitter AST structural graphing with static Model2Vec embeddings and BM25 hybrid search — exposed through a fast CLI and a Model Context Protocol server.

What it is

Ask questions about code. Get ranked context, not a wall of matches.

Traditional grep tells you every place a string appears. code-search tells you where the answer lives. Natural-language queries are scored by a hybrid of lexical BM25 and a static embedding model, then fused into one ranked list. When the question is structural — “who calls this”, “what implements this interface” — it answers from a real call graph instead of guessing.

Everything runs locally: a static model, a local SQLite index under .context/, and a background daemon over a local IPC socket. The MCP server enforces air-gap mode by blocking outbound sockets, redacts secrets in results, and writes an append-only audit log.

Read the pipeline walkthrough
Terminal
# Find the implementation, not every occurrence
$ code-search search "how is JWT validation implemented" --limit 5

# Resolve a symbol by fully qualified name
$ code-search symbol "auth.jwt.validate_token"

# Trace who calls it
$ code-search graph "auth.jwt.validate_token" --direction callers --depth 2

# Exact enumeration when you need every hit
$ code-search search "TODO" --mode exhaustive --matching literal
When to use it. Reach for code-search when you don’t know the identifier, need ranked definitions, or the question is structural. Reach for grep for exact strings and counts — or stay in the tool with --mode exhaustive.

Capabilities

Built for real codebases and strict networks

Search, navigate, and audit a repository from one index — with no GPU and no network dependency at query time.

Hybrid semantic search

BM25 and 32-dim Model2Vec vectors fused with RRF, then reranked with definition and test-file multipliers. Falls back to lexical-only when the model is unavailable — and says so.

Call graph traversal

Callers, callees, implementations, multi-hop queries, and shortest paths. Receiver-qualified calls resolve through declared field, parameter, and local types.

MCP server

Nineteen tools for search, symbols, graph, architecture, coverage, dead code, and Cypher queries — ready for OpenCode, Claude Desktop, or any MCP client.

Air-gap enforcement

Outbound sockets are blocked while serving. The embedding model ships with the bundle, so vector search works on a machine that has never had internet access.

Incremental & watched indexes

SHA256-based incremental re-indexing, optional file watching, stale-index notices, and stale-row pruning. Discovery respects .gitignore by default.

Quality & compliance

Confidence bands, ranking explanations, dependency-free evaluation harness, secret redaction, and an append-only audit log. MIT licensed.

Languages. Python, Java, JavaScript, TypeScript, C#, C++, Bash, Go, Kotlin, Groovy, YAML, TOML are built in. Rust, Ruby, Swift, and PHP are available through the [lang] extra. Custom languages can be added with a JSON config.

Installation

Install it your way

Python 3.11+, 4+ cores, 8 GB RAM. Linux, macOS, or Windows 10 1803+.

Recommended
pipx install --force "git+https://github.com/dhanoopbhaskar/code-search"

Installs the CLI into an isolated environment already on your PATH.

From a built wheel
pip install dist/code_search-*.whl

# Optional extra grammars: Rust, Ruby, Swift, PHP
pip install "dist/code_search-0.1.0-py3-none-any.whl[lang]"

Build first with make build if dist/ is empty.

Editable development install
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

Activate the virtualenv before running code-search.

Offline / air-gapped target
# On a networked machine
./scripts/bundle.sh --deps

# Copy the tarball, then on the target
tar xzf code-search-*-bundle.tar.gz
cd bundle
python install-from-bundle.py

Installs into ./.venv with the embedding model bundled. Only --deps bundles include dependency wheels.

Add .context/ to .gitignore. That directory is your index — SQLite databases and vector files generated per repository.

Verify the install

code-search --help
code-search list-languages
code-search doctor

Quick start

From clone to answer in four commands

1

Get the embedding model

Fetches potion-code-16m-32d from MinishLab. Skip if you installed from a bundle that includes it. Without a model, search degrades to BM25-only.

Terminal
code-search download-models
2

Index the codebase

Writes .context/ in the repository root. Use --incremental on later runs and --watch to keep it current.

Terminal
cd /path/to/your/repo
code-search index --path .

# later, only changed files
code-search index --incremental
code-search index --watch      # keep it live
3

Warm the daemon

Loads the model and index once. Repeated CLI calls forward to it, so the first query is the only slow one.

Terminal
code-search start
code-search status
code-search daemon wait --timeout 30
4

Search

Use short keyword phrases (2–6 words). Add --json for structured output, --paths-only for a compact discovery pass.

Terminal
code-search search "how is JWT validation implemented" --limit 5
code-search search "database connection pool" --content config
code-search search "deployment guide" --content docs
code-search search "validate.*token" --mode exhaustive --regex

Recommended warm invocation

Daily driver
code-search start                       # once per session
code-search search "<query>" --json --paths-only
code-search symbol <Fqn>
code-search view <Fqn|file> --budget 2000
code-search graph <Fqn> --explain-unresolved

CLI reference

One command per question

Every command accepts --json for structured output. Graph answers label each edge with its provenance, and ambiguous symbols are refused with ranked candidates instead of guessed.

search

Hybrid BM25 + vector search with RRF fusion. Modes: ranked, exhaustive, enumerate.

code-search search "retry with exponential backoff" --limit 5
code-search search "TODO" --matching literal
code-search search "list all controllers" --mode enumerate
symbol

Resolve a symbol by FQN. Java overloads accept a full signature.

code-search symbol "auth.jwt.validate_token"
code-search symbol "ArticleService" --outline
view

Read a symbol or file with a compact outline/body contract and token budget.

code-search view "ArticleService" --outline
code-search view src/auth.py --body --max-lines 80
code-search view "ArticleService" --budget 2000
graph

Traverse callers, callees, or implementations. Depth is bounded at 5.

code-search graph "auth.jwt.validate_token" --direction callers
code-search graph "TokenService" --transitive --depth 2
implementations

Static implementers of an interface method or type, with direct/indirect provenance.

code-search implementations "ArticleRepository.findBySlug"
find-related

Semantically similar chunks anchored at a file and line.

code-search find-related src/service.py --line 42 --limit 10
query

Multi-hop graph question seeded from hybrid search. Labels every edge.

code-search query "how does favoriting flow from controller to repository" --depth 3
path

Shortest directed path between two symbols. Ambiguous endpoints are refused.

code-search path "ArticleController.favorite" "ArticleRepository.save"
explain

Metadata, relations, rationale comments, and offline documentation links.

code-search explain "auth.jwt.validate_token"
affected · detect-changes

Map a git diff (or explicit paths) to seeds and impacted symbols.

code-search affected src/auth.py --depth 2
map · architecture

Bounded architecture report: entry points, communities, core symbols.

code-search map --top 15
schema

Stored labels, edge types, resolution tiers, and coverage diagnostics.

code-search schema --diagnostics
outline · symbols

One file’s declarations in order; structural symbol search by kind, regex, or degree.

code-search outline src/auth.py
code-search symbols --kind class --file-pattern "src/**"
dead-code · coverage

Callables with no proven production reference; per-file index gaps.

code-search dead-code
code-search coverage src/auth.py
cypher

Read-only Cypher subset over the indexed graph.

code-search cypher "MATCH (f:Function)-[:CALLS]->(g) RETURN g.name LIMIT 20"
stats · doctor · metrics

Index/profile stats, combined health diagnosis, and query metrics.

code-search stats --format json
code-search doctor
code-search metrics

MCP server

Plug the index into your AI assistant

code-search serve speaks JSON-RPC 2.0 over stdio. Index the target repository before starting it.

OpenCode — ~/.config/opencode/opencode.jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "code-search": {
      "type": "local",
      "command": ["code-search", "serve"],
      "environment": {
        "CODE_SEARCH_CONTEXT_DIR": "/path/to/your/project/.context",
        "CODE_SEARCH_LOG_LEVEL": "WARNING"
      },
      "enabled": true
    }
  }
}

Every tool redacts secrets and attaches a freshness object. High-volume tools accept max_output_tokens and a profile of compact, outline, or full.

Typical agent workflow

  1. Verify the layer — run a search and confirm the vector layer is healthy before trusting semantic ranking.
  2. Explore with search — short keyword phrases beat long prose.
  3. Check confidence — inspect confidence, confidence_band, and borderline; verify low-confidence rows.
  4. Read the symbol — get_symbol_definition for the full implementation.
  5. Trace the graph — get_call_neighbors to understand dependencies.
  6. Verify exactly — use grep for strings and counts, or exhaustive search mode.

Runtime profiles

standard is the default: legacy index layout, blocking freshness. small enables the compact layout and deferred freshness. Existing indexes are never migrated implicitly.

Terminal
code-search index --runtime-profile small --index-layout compact --path .
code-search index --no-graph --force --path .   # search-only
code-search search "validate token" --paths-only --meta full

Air-gapped checklist

  • Build with ./scripts/bundle.sh --deps to include wheels and the model.
  • Install with python install-from-bundle.py — no index download prompt.
  • The daemon uses an AF_UNIX socket (or named pipe), never a network listener.
  • Serve with outbound sockets blocked, secrets redacted, and audit logging on.

Operating notes

Keep it fast and trustworthy

  • Add .context/ to .gitignore — it is generated state, not source.
  • Keep the daemon warm for interactive use; --no-daemon serves one invocation in-process.
  • Run code-search stats --format json to see profile, layout, per-store sizes, and graph coverage.
  • When an answer is empty, check coverage before assuming absence — parse_partial and skipped_oversized files are reported explicitly.
  • Prefer short queries. If ranked search misses, try alternate phrasing before falling back to grep.
Don’t use ranked search for exact enumeration. For literal strings, regex, or counts, switch to --mode exhaustive (with --matching / --regex) — or use grep.
